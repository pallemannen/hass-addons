# HA Redirect

Minimal Home Assistant add-on that does blind TCP port forwarding on the
local server - listenening on as many ports as you list and relays all
traffic on any of them straight to Home Assistant's real port on the same
machine. Perfect for post-2026.8.0 users that are migrating from port 8123
to port 80 - now both can work simultaneously.

See [DOCS.md](DOCS.md) for full configuration details.
